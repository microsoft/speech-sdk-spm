# Microsoft Cognitive Services Speech SDK for Swift Package Manager

This repository provides the Swift Package Manager (SPM) distribution of the Microsoft Cognitive Services Speech SDK for Apple platforms.

## Requirements

- Xcode 15 or later
- Swift Package Manager
- iOS, macOS, tvOS, or visionOS (see package manifest for supported versions)

## Add the Package

In Xcode:

1. Select **File > Add Package Dependencies**
2. Enter:

https://github.com/microsoft/speech-sdk-spm

3. Choose the desired version
4. Add the package to your target

## Usage

```swift
import MicrosoftCognitiveServicesSpeech
``
